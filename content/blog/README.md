# Blog posts

Add a Markdown file here to publish a post — it appears in the Writing section and at `/blog/<file-name>`.

```md
---
title: Building a vehicle tracker with YOLO and OpenCV
date: 2026-11-20
summary: What worked, what broke, and what I'd do differently.
tags: [computer vision, yolo]
draft: false
---

Your post in **Markdown**...
```

- Files starting with `_` and this README are ignored.
- Set `draft: true` to hide a post without deleting it.
